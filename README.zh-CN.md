# Fleet Operations 舰队手动瞄准

[English](README.md) · [下载与发布](https://github.com/wangchuanyu666/FleetOperations-UAD/releases)

用于《Ultimate Admiral: Dreadnoughts》的 Windows x64 实验模组。当前 **0.0.8.1-export-r1**，提供火炮/鱼雷独立手动瞄准、齐射、散布显示、射击建议和中英文改键界面。与现代舰 P0、UAD Commander 分开运行。

## 安装

从 Releases 下载 Windows ZIP，完整解压到普通英文目录，如 `C:\UAD-FleetAim-0081`。关闭游戏，运行 `Install.cmd` 并指定自己的兼容原版目录；成功后用 `Start.cmd`。需要 Steam 登录、首次联网和至少约 6GB 空间。安装器从自己的游戏复制约 4.19GB 独立副本，并从官方地址下载校验固定依赖。首次加载需要生成引用。

源码下载/仓库克隆不含编译 payload，不能直接用 Install.cmd 当运行包安装。游戏文件精确哈希不匹配时请保留报错，不要跳过校验。不要直接把 DLL 放进原版。

进入后新建自定义战斗，读档战斗不启用实验。独立存档初始为空；游戏本体、私人存档、日志和第三方二进制不随包分发。

## 默认操作

| 按键 | 动作 |
| --- | --- |
| Ctrl+K | 火炮固定瞄准鼠标点 |
| Ctrl+O | 火炮跟随鼠标开关 |
| Ctrl+I | 向当前瞄点请求逐炮塔齐射 |
| Ctrl+Y | 鱼雷独立跟随鼠标开关 |
| Ctrl+U | 请求鱼雷发射 |
| Ctrl+L | 恢复选中舰原版指令 |
| Ctrl+B | 射击建议开关 |
| Ctrl+N | 设置、中英文和改键 |

射击建议：先明确点选一个可见敌舰，再选回己方发射舰。蓝/紫点为首主炮/首鱼雷座参考，按立即发射、目标匀速估计，不会自动瞄准或开火。设置支持 Ctrl/Alt/Shift 组合，保留 F1–F10/J，有效修改立即保存并备份。

实时圈随当前瞄点更新；橙圈及小十字为已发齐射冻结区域/海面终点，跟踪弹体结束后清除。鱼雷发射后不留历史扇面，持续显示当前瞄准线；关闭散布仍保留名义鱼雷线。保留原版弹药、装填、射程和射界，不能保证同时出弹。

## 精度与验证范围

读取原版最终设计精度，以直径20m参考靶校准自由瞄准散布；不等于完整原版锁定目标校射或全部即时运动精度修正。圈是外边界，不是概率圈，也不保证命中真实舰船。原生精度不可用时明确标注“距离散布后备”。

此版修正了0.0.8的原生动态调用、空参数包装及共用桥连锁停用问题。**已做编译和静态审核；移机安装、画面及修复后的实战效果仍待用户验收。** 不把界面出现、加载成功或静态通过当作实战通过。本仓库保留测试源码，未将旧测试数量列作本版通过证明。

## 构建和数据

需要 .NET 6 SDK（仅运行时不够）及自己的兼容 MelonLoader/游戏生成引用：

```powershell
.\Build-Source.ps1 -GameDirectory 'C:\UAD-FleetAim-0081\lab\fleet-operations\game'
```

构建只写输出目录，不启动或部署游戏。更多见 [构建说明](BUILD_README.zh-CN.txt)。重新编译后替换运行包时需同步 marker 中 payload 哈希，在新目录重新安装。

独立数据为 `lab/fleet-operations/userdata`，启动日志为 `lab/fleet-operations/logs`。更新前备份 userdata，建议新目录安装；退出游戏后删除自己解压的包即可卸载，原版从 Steam 启动。
